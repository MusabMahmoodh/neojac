# E1615 to E1637: type parameter packs, wide text, C++ and Rust templates, C++ constructors, objects lent to C, sizeof, and managed places

A type parameter pack, `*Ts` among a function's type parameters, types the function's `*`
parameter (`*args: *Ts`) with the types of the arguments each call gives it, one by one, and each
call is compiled for them. These codes report a pack declared or used where it cannot be, and a
call that does not give it its types one by one. See
[Type parameter packs](../../language/generics.md#type-parameter-packs) (`neojac docs type parameter pack`).

E1619 reports `ptr[u16]()` or `ptr[u32]()` of a `str` that is no literal. E1620 and E1622 report a
C++ member or function template's instance that the program's build cannot make, and E1625 a Rust
generic function's. E1621 reports a call of a C++ class that is not its default constructor, E1635
a value lent to C by `hold` that is no counted object, E1636 `sizeof` of a type C does not lay out,
and E1637 an `own` binding that would take a value whose drop runs code from a managed place.

## E1615

```text
the type parameter pack '{pack}' is not where a pack can be: {why}
```

`{pack}` is declared or used where a pack cannot be, and `{why}` says which: a class or a type
alias declares one (a function or a method does), a function declares a second, the pack types no
`*` parameter of its function, or the pack is written elsewhere than as `*Ts`, the type of the `*`
parameter (a local typed `Ts`).

```jac
# expect: E1615 x2
def two[*Ts, *Us](*args: *Ts) -> int {
    return len(args);
}

obj Box[*Ts] {
    has n: int = 0;
}

with entry {
    print(two(1), Box().n);
}
```

**Fix:** declare one pack, on the function whose `*` parameter it types, and use the `*`
parameter (`args`, a tuple) where the values are needed. A class that holds values of several
types holds them as a `tuple` or as fields.

## E1616

```text
`*{name}` types a `*` parameter by a type parameter pack, and this function declares no pack of that name
```

A `*` parameter is typed `*{name}`, the form that names a pack, and `{name}` is no pack of the
function: an ordinary type parameter, or a name it does not declare.

```jac
# expect: E1616
def other[U, *Ts](*args: *U) -> int {
    return len(args);
}

with entry {
    print(other(1));
}
```

**Fix:** type the `*` parameter by the function's pack (`*args: *Ts`), or, for arguments of one
type, by a type (`*args: U`).

## E1617

```text
{callee} takes a type parameter pack, which each call's arguments give: it takes no type arguments
```

A call of a function with a type parameter pack writes type arguments in brackets. The pack's
types are the arguments' own, so a call gives them by its arguments alone.

```jac
# expect: E1617
def count[*Ts](*args: *Ts) -> int {
    return len(args);
}

with entry {
    print(count[int](1));
}
```

**Fix:** drop the brackets (`count(1)`), and convert an argument where it should be of another
type (`count(float(1))`).

## E1618

```text
{callee}'s type parameter pack is given by its arguments one by one, and a spread whose length is not known where it is compiled cannot give it
```

A call spreads a value whose length is known only as the program runs, a list, into a function's
pack. Each call is compiled for the types of the pack's arguments, one by one, so their number is
fixed where the call is compiled. A spread of a tuple gives one argument for each of its items,
and is accepted; a spread of the function's own `*args` is a tuple too.

```jac
# expect: E1618
def count[*Ts](*args: *Ts) -> int {
    return len(args);
}

with entry {
    held = [1, 2];
    print(count(*held));
}
```

**Fix:** pass the values one by one, or as a tuple (`count(*(1, 2))`); or give the function a
`*` parameter of one type (`def count(*args: int)`), which takes a list's spread.

## E1619

```text
{ty}() of a str is the static NUL-ended text of a string literal, and this str is no literal
```

`ptr[u16]("text")` and `ptr[u32]("text")` are a string literal's text as C's `u"text"` and
`U"text"` are: static data, UTF-16 or UTF-32, NUL-ended, made where the program is compiled. A
`str` made as the program runs has no such data, so `{ty}`, `ptr[u16]` or `ptr[u32]`, is given a
literal only. See [Strings](../../interop/c-libraries.md#strings).

```jac
# expect: E1619
with entry {
    name = "abc" + str(3);
    print(ptr[u16](name)[0]);
}
```

**Fix:** write the text as a literal (`ptr[u16]("abc3")`). Text made as the program runs is
encoded into bytes of its own, NUL-ended where C reads to a NUL
(`(name + "\0").encode("utf-16-le")`), and passed to a parameter that takes `bytes`.

## E1620

```text
the C++ class '{cls}' has no instance {name}[{args}] of its member template: the template does not take these type arguments, or one is no class or number type of C++
```

A call names an instance of a C++ class's member function template, `o.{name}[{args}](...)`, that
the program's build could not make. Each instance a program names is made by reading the module's
headers again with it asked for; this one is no instance, since the template does not compile with
these arguments, or an argument is a Jac type C++ has no type for (a `str`, a list). See
[Member function templates](../../interop/c-modules.md#member-function-templates).

<!-- example: not checked: needs the C++ header library whose Counter has the member template to<T>() -->
```jac
with entry {
    c = Counter.make(i32(7));
    print(c.to[float](), c.to[str]());
}
```

```text
main.jac:3:31: error[E1620]: the C++ class 'Counter' has no instance to[str] of its member template: the template does not take these type arguments, or one is no class or number type of C++
```

E1620 is reported where the program names another instance of the template that the build makes,
`c.to[float]()` above. Where `c.to[str]()` is the program's only instance of `to`, the class has no
member `to` at all, and the call is E1030 (`Counter has no field 'to'`).

**Fix:** give type arguments the template takes: a class of the module, a `libcxx` class or a
number type (`c.to[float]()`); for a string, a `libcxx` `std_string` where the template makes one.

## E1621

```text
calling the C++ class '{cls}' makes it by its default constructor, and {why}: a constructor is one of its make members
```

A call of a C++ class's type, `T()`, makes the object by the class's default constructor, as
`T t;` makes it in C++. Jac has no overloading, so a call of the type is that constructor alone:
it takes no arguments, and the class must have a default constructor the interface binds. `{why}`
says which of the two the call misses. A constructor that takes arguments is one of the class's
`make` members, named by its parameters (`make`, `make_i32`, `make_ptr_i8`). `{cls}` is the
class as the program writes it, an instance by its template form: `std_vector[i32]`. See
[What Jac uses of C++](../../interop/c-modules.md#what-jac-uses-of-c).

```jac
# expect: E1621
import from libcxx { std_vector }

with entry {
    v: own std_vector[i32] = std_vector[i32](u64(3));
    print(v.size());
}
```

**Fix:** call the class with no arguments where it has a default constructor
(`std_vector[i32]()`), or the `make` member of the constructor the arguments are for.

## E1622

```text
the C++ function template '{name}' has no instance {name}[{args}]: the template does not take these type arguments, or one is no class or number type of C++
```

A call names an instance of a header library's free function template, `{name}[{args}](...)`,
that the program's build could not make. Each instance a program names is made by reading the
module's headers again with it asked for; this one is no instance, since the template does not
compile with these arguments, or an argument is a Jac type C++ has no type for (a `str`, a list).
See [Function templates](../../interop/c-modules.md#function-templates).

<!-- example: not checked: needs the C++ header library whose kept is a function template -->
```jac
with entry {
    print(kept_[float](2.5), kept_[str]("x"));
}
```

```text
main.jac:2:36: error[E1622]: the C++ function template 'kept_' has no instance kept_[str]: the template does not take these type arguments, or one is no class or number type of C++
```

**Fix:** give type arguments the template takes: a class of the module, a `libcxx` class or a
number type (`kept_[float](2.5)`); for text, the member of the name's set that takes a C string
(`kept_ptr_i8("x")`), where there is one.

## E1625

```text
the Rust function '{name}' has no instance {name}[{args}]: its bounds do not hold for these type arguments, or one is no type Jac gives Rust
```

A call names an instance of a Rust generic function of another crate, `{name}[{args}](...)`, that
rustc could not make. Each instance a program names is asked of rustc when the module is read, and
made for the program; this one is no instance, since a bound of the function's type parameters
does not hold for these arguments (`size_of<T>` takes a `T: Sized`, and Rust's `str` has no fixed
size), or an argument is a Jac type Rust has no type for. See
[Slices, iterators and generic methods](../../interop/rust-modules.md#slices-iterators-and-generic-methods).

```jac
# expect: E1625
import from std.mem { size_of }

with entry {
    print(size_of[u32](), size_of[str]());
}
```

**Fix:** give type arguments that meet the function's bounds: a number type, `str` where the
function takes `&str` or `AsRef<str>`, `Slice[u8]` for `&[u8]`, a Rust type of the program
(`size_of[Vec[u8]]()`).

## E1635

```text
hold() lends C a counted object, and {what} is {type}
```

`hold(x)` gives C a reference to the Jac object `x`, which `held[T](p)` takes back and
`release(p)` gives up. Only a counted object can be held so: an instance of an `obj`, `node`,
`edge` or `walker`. `{what}` is `hold()`'s argument, whose type `{type}` is a number, a str, a
struct or a C record, or `held()`'s type, a struct or a C record. See
[Objects C keeps](../../interop/pointers-and-native-memory.md#objects-c-keeps-hold-held-held_at-release).

```jac
# expect: E1635 x2
import from c {
    obj Pair {
        has a: i32,
            b: f32;
    }
}

with entry {
    p = hold(5);
    print(held[Pair](p).a);
}
```

**Fix:** lend C plain data with `pin` (`pin(5)`), or a pointer to C memory as it is; hold an
object of an `obj` (`hold(Tally())`) and take it back as its class (`held[Tally](p)`).

## E1636

```text
sizeof() takes a type C lays out (a number, a bool, a ptr, a C record, a struct of those or an array of them), and {type} is none
```

`sizeof(T)`, from `jaclang.comptime`, is the bytes C lays a `T` out in, as C's `sizeof` is. A type
C has no layout for has no size: `{type}` is an `obj`, `node`, `edge` or `walker`, whose instances
Jac counts and keeps by reference, a `str`, a collection, or a struct holding one. See
[Compile-time values](../../language/compile-time-values.md#bits-signed-and-sizeof).

```jac
# expect: E1636 x2
import from jaclang.comptime { sizeof }

obj Box {
    has n: int = 0;
}

with entry {
    print(sizeof(Box), sizeof(list[int]));
}
```

**Fix:** ask the size of what C holds: a struct of numbers (`struct Box { has n: int = 0; }`,
`sizeof(Box)` is 8), or a `ptr` where C keeps a reference to a Jac object (`sizeof(ptr)`, with
`hold`).

## E1637

```text
'{place}' is a managed place of a {cls}, whose drop runs code: an `own` binding would end the value while the place still refers to it; bind it with `own` where it is made, and move that owner
```

A value whose drop runs code (a Rust value whose drop is significant, a C++ class whose destructor
is not trivial, a class that owns a field of one) is taken from a managed place into an `own`
local, or given to an `own` or `lin` parameter. `{place}` is that place: a local or parameter with
no ownership annotation, a global, a field with none, an item of a container that does not own
its items, or a call (`'kept(...)'`) of a function whose result may be the value of one of those.
A function's result may be such a value where a `return` of it gives a field with no ownership
annotation, a global, a parameter with none, `self`, an item of a container that does not own its
items, a local that took one of those, or the result of a call that may give one. A function
declared `-> own T`, a constructor, and a function whose `return`s give only what it made or what
an owner gave up give a value an owner may take. `{cls}` is the value's class as the program
writes it. A managed place shares its
value, which ends when its last reference goes; an owner ends its value where its scope ends,
whatever else refers to it. So the place would still refer to a value that has ended. See
[Values whose drop runs code](../../language/ownership.md#values-whose-drop-runs-code-dropped-where-their-scope-ends).

```jac
# expect: E1637 x3
import from std.collections { HashSet }

obj Seen {
    has s: HashSet[u32];
}

def kept(k: Seen) -> HashSet[u32] {
    return k.s;
}

def taken(k: Seen) -> bool {
    s = HashSet[u32].new();
    t: own HashSet[u32] = s;
    u: own HashSet[u32] = k.s;
    v: own HashSet[u32] = kept(k);
    return t.is_empty() and u.is_empty() and v.is_empty();
}
```

**Fix:** bind the value with `own` where it is made, and move that owner
(`s: own HashSet[u32] = HashSet[u32].new(); t: own HashSet[u32] = s;`), or leave the binding
managed (`t = s;`), which shares the value.
